Functional Testing Infrastructure


Setup
=====

Download the baseline variants with `bash download.sh`. This will take single chromosomes from different benchmarks.
Note that the MIMS benchmark and reads from data.smaht.org require `$ACCESS_KEY_ID` and `$SECRET_ACCESS_KEY` environment
variables from your setup SMaHT account.

There's some python requirements, too. See `../gqcalibration`.

Running
=======

Use `bash kanpig_tests.sh`.
